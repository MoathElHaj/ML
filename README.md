# موقع بريق · Bariq Digital Agency

موقع وكالة بريق الرقمية مع لوحة تحكم متصلة بـ Supabase.

- **الموقع:** الرئيسية، خدماتنا، أعمالنا، من نحن، المدونة، تواصل معنا، احجز استشارة مجانية، وزر واتساب عائم.
- **لوحة التحكم (`/dashboard`):** إدارة الخدمات والأعمال والمقالات بمحرّر نصوص مع إدراج الصور وحقول SEO لكل لغة، الباقات والأسعار، جدول الاستشارات (قائمة وتقويم شهري، تأكيد مع دعوة تقويم بالبريد، تذكير تلقائي قبل الموعد بيوم، تصدير Excel)، صندوق رسائل التواصل، وصفحة **الإعدادات** (أوقات العمل والإجازات، بريد SMTP وإشعاراته، وأكواد GTM / GA4 / Google Ads / Meta Pixel).
- **الفريق والصلاحيات:** مالك ومدير وعضو فريق، ولكل عضو الأقسام المسموح بها فقط (مطبّقة في قاعدة البيانات عبر RLS، لا في الواجهة فقط). من «المستخدمون والصلاحيات» تضيف المستخدم بكلمة مرور مؤقتة، وتعدّل صلاحياته، وتوقفه أو تحذفه.
- **لوحة بلغتين:** العربية هي الأساس، وزر English في القائمة الجانبية يحوّل اللوحة للإنجليزية (يُحفظ لكل مستخدم).
- **المهام:** «يومي» (متأخرة، اليوم، غداً، هذا الأسبوع)، لوحة سحب وإفلات حسب الحالة، وعرض أسبوعي تسحب فيه المهام بين الأيام. إضافة سريعة، أولوية، مسؤول، ومهام متكررة (يومياً، أيام العمل، أسبوعياً، شهرياً).
- **العملاء:** مراحل البيع (جديد ← تم التواصل ← مهتم ← عرض سعر ← تم التعاقد)، سجل تواصل لكل عميل، ومهمة متابعة تلقائية لكل عميل جديد. يُضاف العملاء تلقائياً من الحجوزات ورسائل الموقع (مع الحملة التي جاؤوا منها: Google Ads أو Meta أو UTM)، ومن رسائل واتساب وإعلانات «انقر للمراسلة»، ومن نماذج إعلانات إنستغرام وفيسبوك.
- **SEO و GEO (محركات البحث بالذكاء الاصطناعي):** بيانات منظّمة JSON-LD (المنظمة، الخدمات، الباقات، الأسئلة الشائعة، المقالات، مسار التنقل)، ملف `/llms.txt` يلخّص الوكالة لنماذج الذكاء الاصطناعي، و`robots.txt` يسمح لزواحف البحث بالذكاء الاصطناعي ويحجب لوحة التحكم.
- **لغتان ووضعان:** العربية هي الأساس على الروابط العادية (`/services`)، والإنجليزية على `/en/...` مع زر تبديل اللغة في الهيدر. الوضع الفاتح هو الأساس، وزر القمر يفعّل الوضع الداكن ويتذكّر اختيار الزائر.
- **التقنيات:** Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · Supabase (Postgres + Auth + Storage) · الخط IBM Plex Sans Arabic · واجهة RTL.

## 1. إعداد Supabase

1. أنشئ مشروعاً في [supabase.com](https://supabase.com).
2. من **SQL Editor** شغّل ملفات `supabase/migrations/` بالترتيب: `0001_init.sql` (الجداول، صلاحيات RLS، مخزن الصور `media`)، ثم `0002_english_content.sql` (حقول المحتوى الإنجليزي)، ثم `0003_meta_ads.sql` (ربط Meta والحملات)، ثم `0004_settings_pricing_email.sql` (الإعدادات، الباقات، الإجازات، سجل البريد، حقول SEO)، ثم `0005_team_tasks_clients.sql` (الأدوار والصلاحيات، المهام، العملاء وربطهم التلقائي). أول حساب مدير موجود يصبح «المالك» تلقائياً.
3. شغّل `supabase/seed.sql` لإضافة الخدمات الأربع بالعربية والإنجليزية.
4. أنشئ حساب المدير: **Authentication → Users → Add user** (بريد وكلمة مرور)، ثم امنحه صلاحية لوحة التحكم:

   ```sql
   insert into public.admins (user_id, email, role)
   select id, email, 'owner' from auth.users where email = 'you@example.com';
   ```

> الزوار يستطيعون فقط إرسال الحجوزات والرسائل وقراءة المحتوى المنشور. كل التعديلات والقراءة الخاصة محصورة بالمستخدمين الموجودين في جدول `admins`.

## 2. متغيرات البيئة

انسخ `.env.example` إلى `.env.local` واملأ القيم:

| المتغير | الوصف |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | رابط المشروع (Project Settings → API) |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | المفتاح العام anon / publishable |
| `NEXT_PUBLIC_SITE_URL` | رابط الموقع النهائي (للـ SEO وخريطة الموقع) |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | رقم واتساب بالصيغة الدولية، أرقام فقط. الافتراضي رقم بريق `96894178876` |
| `NEXT_PUBLIC_BUSINESS_TIMEZONE` | المنطقة الزمنية لمواعيد الاستشارات (الافتراضي `Asia/Muscat`) |
| `NEXT_PUBLIC_CONTACT_EMAIL` / `PHONE` / `ADDRESS` | بيانات التواصل (اختيارية) |
| `SUPABASE_SERVICE_ROLE_KEY` | مفتاح الخادم (Project Settings → API → service_role). **سرّي** — يُستخدم على الخادم فقط لإرسال البريد والتذكيرات والتأكيد التلقائي |
| `CRON_SECRET` | نص عشوائي طويل يحمي رابط التذكيرات اليومي `/api/cron/reminders` (يرسله Vercel تلقائياً) |
| `NEXT_PUBLIC_INSTAGRAM_URL` / `FACEBOOK_URL` / `LINKEDIN_URL` / `X_URL` / `TIKTOK_URL` | روابط حسابات التواصل في الفوتر (يظهر كل حساب عند إضافة رابطه) |

## 3. ربط Meta والحملات الإعلانية بالذكاء الاصطناعي (اختياري)

من **لوحة التحكم ← الحملات الإعلانية** تربط حساب Meta، ثم يكتب الذكاء الاصطناعي (Claude) حملة «انقر للمراسلة على واتساب»: النصوص، الاستهداف، رسالة الترحيب والأسئلة السريعة. تراجعها وتعدّلها، ثم تُنشأ في حسابك الإعلاني **متوقفة (PAUSED)** — لا يُصرف أي مبلغ حتى تفعّلها بنفسك من مدير الإعلانات.

المتطلبات في Meta:
1. **Business Portfolio** فيه حساب إعلاني نشط وطريقة دفع.
2. **صفحة فيسبوك** مرتبط بها رقم **واتساب بيزنس** (Meta Business Suite ← الإعدادات ← الحسابات المرتبطة ← WhatsApp).
3. **تطبيق Meta**: من [developers.facebook.com](https://developers.facebook.com/apps) أنشئ تطبيقاً من نوع *Business*، أضف منتج **Facebook Login for Business** و **Marketing API**، وضع في *Valid OAuth Redirect URIs*:
   `https://موقعك/api/meta/callback` (ومحلياً `http://localhost:3000/api/meta/callback`).
4. أضف إلى متغيرات البيئة: `META_APP_ID` و `META_APP_SECRET` و `ANTHROPIC_API_KEY` (من [console.anthropic.com](https://console.anthropic.com)).
5. شغّل `supabase/migrations/0003_meta_ads.sql`.

> ما دام تطبيق Meta في وضع التطوير (Development) يعمل الربط لحسابات مسؤولي التطبيق فقط، وهذا يكفي لاستخدام بريق الداخلي.

## 4. البريد الإلكتروني والتتبع

**البريد:** من **لوحة التحكم ← الإعدادات ← البريد الإلكتروني** أدخل بيانات SMTP (مثلاً Google Workspace: `smtp.gmail.com`، المنفذ 587، وكلمة مرور تطبيق App Password) والعناوين التي تستقبل الإشعارات، ثم «إرسال رسالة تجريبية». عند كل حجز أو رسالة من «تواصل معنا» يصل إشعار للفريق (الرد عليه يذهب للعميل مباشرة)، ويستلم العميل تأكيداً. وعند تأكيد الموعد تصله دعوة تقويم `.ics`، ثم تذكير قبل الموعد بيوم (Vercel Cron يومياً عبر `vercel.json`). كلمة المرور تُحفظ في جدول خاص لا يُقرأ إلا على الخادم، وكل رسالة تظهر في «سجل البريد».

**التتبع:** من **الإعدادات ← التتبع والتحليلات** أضف معرّف Google Tag Manager أو GA4، ومعرّف Google Ads وتصنيف تحويل العملاء المحتملين، و Meta Pixel. تُسجَّل كل استشارة أو رسالة تلقائياً كتحويل `generate_lead` / `Lead`.

**واتساب (WhatsApp Cloud API):** من **الإعدادات ← التكاملات** أدخل Phone number ID ورمز الوصول، ثم ضع رابط Webhook ورمز التحقق الظاهرين هناك في إعداد WhatsApp داخل تطبيق Meta واشترك في `messages`. كل رسالة واردة تصبح عميلاً، ويمكنك الرد من صفحة العميل.

**نماذج إعلانات Meta:** بعد ربط Meta من «الحملات الإعلانية» اضغط «جلب نماذج Meta» في صفحة العملاء (تُجلب تلقائياً أيضاً مع المهمة اليومية). تحتاج صلاحية `leads_retrieval`، لذا أعد ربط Meta مرة واحدة إن كان مربوطاً قبل هذه الإضافة.

## 5. التشغيل محلياً

```bash
pnpm install
pnpm dev
```

ثم افتح `http://localhost:3000` ولوحة التحكم على `/login`.

**Supabase محلي (اختياري، يحتاج Docker):** `npx supabase start` يشغّل قاعدة بيانات محلية على المنافذ `553xx` ويطبّق الملفات تلقائياً.

## 6. النشر

انشر على Vercel (أو أي استضافة تدعم Next.js)، وأضف متغيرات البيئة نفسها في إعدادات المشروع.

## اللغات

- نصوص الموقع كلها في `src/lib/i18n.ts` (قاموس عربي وإنجليزي).
- محتوى قاعدة البيانات: كل نموذج في لوحة التحكم فيه قسم **«النسخة الإنجليزية»** اختياري. إذا تُرك فارغاً يُعرض النص العربي للخدمات والأعمال.
- المقالات تظهر في المدونة الإنجليزية فقط إذا كان لها عنوان ومحتوى بالإنجليزية.
- لوحة التحكم نفسها بالعربية وبالوضع الفاتح دائماً.

## تخصيص سريع

- **أيام وأوقات الاستشارات:** `src/lib/site.ts` → `booking` (أيام العمل، الأوقات، عدد الأيام المتاحة، مدة الجلسة).
- **الألوان والخط:** `src/app/globals.css` (ألوان الهوية: `#230b4b` `#3a1673` `#612aae` `#cda9ff`). ألوان الوضع الداكن في كتلة `.dark` بالملف نفسه.
- **باقات التسويق:** `src/lib/content.ts` → `packagesData`.
- **صور الموقع:** `public/images/`.
